System Monitor

A Linux system monitoring application built with a C backend and a Python desktop GUI.

Goals

Monitor running processes and their resource usage.

Calculate CPU utilization from successive measurements.

Track memory consumption over time.

Sort and filter processes by resource usage.

Export monitoring data to CSV.

Provide a desktop dashboard for viewing live statistics.

Technology

C for the monitoring engine

Linux /proc filesystem for process information

Python and PySide6 for the desktop GUI

Git for version control

Status

Initial project setup.
